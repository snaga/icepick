# 0006. レガシーコマンド（check, rewrite, patch）の削除と処方箋駆動パイプラインへの純化

* **ステータス**: Accepted
* **決定日**: 2026-09-13

---

## 1. 背景と課題 (Context)

Icepick では、初期のアーキテクチャ（ADR-0001）において以下の第1世代パイプラインを採用していました：
- `icepick check`: Linter による静的ルール違反の診断とテーブル表示
- `icepick rewrite`: AST 置換と全行再生成またはスライシングによる Unified Diff 出力
- `icepick patch`: 生成された `.patch` ファイルを読み込んで対象ファイルに適用

しかし、ADR-0005（処方箋ファーストアーキテクチャの導入）により、ノード単位で一意な処方箋ID（`RX-001`, `RX-002`...）を採番し、狙い撃ちで差分生成とファイル直接適用を行う第2世代パイプライン（`diag` ➔ `diff` ➔ `fix`）が完成しました。

これにより、以下の課題が顕在化しました：
1. **完全な下位互換と機能重複**:
   - `check` は `diag` の完全な下位互換であり、処方箋IDも理由・期待効果もJSON出力も持たない。
   - `rewrite` は `diff` と役割が100%重複しており、`diff` の方が `--rx` による狙い撃ち差分生成が可能な上位互換である。
   - `patch` は `fix` が直接ファイルを安全にインプレース修正できるため存在意義を失っており、外部パッチ適用であれば標準の `git apply` で事足りる。
2. **CLI コマンド乱立によるエージェント・利用者の認知負荷**:
   - `--help` を表示した際にサブコマンドが10個も並び、自律型 AI エージェントや開発者が「`check` と `diag` のどちらを使うべきか」「`rewrite` と `diff` の違いは何か」と混乱する要因となっていた。

---

## 2. 決定事項 (Decision)

### ① レガシーサブコマンドの完全削除
- CLI から以下の3つのサブコマンドを完全削除します：
  - `icepick check`
  - `icepick rewrite`
  - `icepick patch`

### ② コマンド体系の 4 大コマンドへの純化
- Icepick の公開コマンド体系を以下の 4 つの主軸コマンド（＋運用・設定系）に純化します：

| コマンド | 役割・責務 |
|:---|:---|
| **`icepick diag <file>`** | クエリを診断し、一意な処方箋（RX-001...）をカード表示または JSON で提示 |
| **`icepick diff <file>`** | 処方箋を元に最小限の Unified Diff を生成（`--rx` による狙い撃ち対応） |
| **`icepick fix <file>`** | 処方箋を元ファイルへ直接インプレース適用（`--rx`, `--dry-run`, `--force` 対応） |
| **`icepick verify <orig> <opt>`** | 2つのクエリの等価性を判定する双方向 EXCEPT SQL を生成（snow CLI 外部委譲） |

※ 運用・エージェント連携系として `config` (show/test), `feedback`, `agent-context` を維持。

### ③ LLM 連携能力 (`--agentic`) の継承
- 旧 `rewrite --agentic` に実装されていた LLM 連携（相関サブクエリ等の高度な局所リライト）は、`diag --agentic` および `diff --agentic` のオプションとして引き継ぎます。

---

## 3. 影響とメリット (Consequences)

### メリット (Positive)
1. **極めてシンプルで直感的な CLI UX**:
   - `--help` の表示が一目瞭然となり、AI エージェントや開発者が迷う余地がゼロになる。
2. **コードベースの軽量化と保守性向上**:
   - `cli.py` 内の重複していたコマンドハンドラや、旧パイプライン用の引数分岐が削減され、保守性が劇的に向上する。
3. **ワークフローの一貫性**:
   - 「診断 (`diag`) ➔ 確認 (`diff`) ➔ 適用 (`fix`) ➔ 検証 (`verify`)」という、統一された美しいライフサイクルが確立される。
